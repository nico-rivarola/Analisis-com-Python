# 📊 Python Insights - Analisando Dados com Python

### 🔍 Análise de Dados: Redução de Cancelamentos de Clientes

---

## 🧠 Visão Geral

Este projeto foi desenvolvido com o objetivo de ajudar uma empresa com mais de **800 mil clientes** a entender e reduzir a taxa de cancelamento de seus serviços.  
Através de uma análise profunda de dados, buscamos identificar os principais motivos que levam os clientes a cancelarem seus contratos e sugerir **ações práticas** para aumentar a **retenção** e melhorar a **satisfação geral**.

---

## 🏢 Contexto do Projeto

A empresa enfrenta um grande desafio: a maior parte de sua base de clientes tornou-se **inativa**, ou seja, **cancelou os serviços oferecidos**. Isso impacta diretamente:

- Os **resultados financeiros** 📉  
- A **sustentabilidade do negócio** 🌱

Como parte da solução, este projeto foi contratado com os seguintes objetivos:

1️⃣ Identificar os fatores que contribuem para os cancelamentos  
2️⃣ Analisar dados históricos dos clientes, buscando padrões e fatores-chave  
3️⃣ Criar estratégias de retenção para reduzir os cancelamentos

---

## 🎯 Objetivos

- 🔎 Analisar e tratar dados de clientes  
- 🧹 Limpar inconsistências nos dados  
- 📈 Preparar as informações para análise preditiva  
- 🤖 Sugerir ações baseadas em dados para retenção de clientes
